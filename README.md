## 👨‍💻 About Me

Hi, I'm **Soheil Mohajer** 👋 — a **Computer Engineering student** from **Mashhad, Iran**, working as an **Android & AI Agent Developer**.

I build Android apps and games, and AI agents with **n8n** and **Python** — from game logic and UI all the way to **publishing on Cafe Bazaar**. I'm also a co-founder of **Zenithra**, where we build modern, scalable, high-quality software products.

- 🔭 Building real-world **Android apps & games** with Kotlin, Compose and Unity

- 🌱 Currently learning **Kotlin Compose** and **Docker**
- 🤝 Open to work in **Android, Unity and AI-agent development**
